# Химия · ОГЭ

Статический сайт для подготовки к ОГЭ по химии. Без сборки и зависимостей: HTML + CSS + JavaScript-модули, контент — в JSON. Работает на GitHub Pages, устанавливается на телефон (PWA), работает офлайн.

## Что внутри

| Раздел | Зачем |
|---|---|
| **Путь уроков** | Интерактивные уроки по темам: ползунки, сборка формул, вычёркивание ионов, задания с целью |
| **Блиц** | 10 вопросов на скорость (20 с), очки за быстроту, личные рекорды |
| **Повторение** | Интервальное повторение: задания и карточки возвращаются через 1, 3, 7, 14, 30 дней; ошибки — в тот же день |
| **Тренировка** | 10 заданий вперемешку по навыкам, формат ОГЭ (выбор, «выберите два», соответствие, число), частичные баллы как на экзамене |
| **Разбор** | Пошаговые решения → затем такие же задачи, где следующий шаг выбирает ученик |
| **Карточки** | Вспомнить → открыть → оценить себя |
| **Лаборатория** | Смешивание любых двух растворов: сначала предсказание, потом результат и уравнения |
| **Распознавание** | Бесконечные варианты практического задания: две склянки, три реактива |
| **Справочник** | Таблица растворимости и шпаргалки всех тем, печать |
| **Доска** | Своя доска + ссылка на совместную доску Excalidraw для занятий |
| **Прогресс** | Навыки, уверенные ошибки, отчёт преподавателю, перенос данных |

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Через минуту сайт доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Локально: `python3 -m http.server` в папке сайта и откройте `http://localhost:8000`. Открыть `index.html` как файл нельзя — браузер не разрешит загрузку JSON.

## Как добавить новую тему

1. Скопируйте `content/modules/calc.json` в `content/modules/<id>.json` и замените содержимое.
2. Добавьте `<id>` в список `modules` в `content/manifest.json`.

Код менять не нужно. Тема сама появится на главной, в тренировке, повторении, справочнике и прогрессе.

### Структура модуля

```json
{
  "id": "salts",
  "title": "Название темы",
  "summary": "Одна строка",
  "skills": [{ "id": "s1", "title": "Навык" }],
  "cheatsheet": [ ...блоки ],
  "examples":   [ ...разборы ],
  "questions":  [ ...задания ],
  "cards":      [ ...карточки ]
}
```

**Формулы** пишутся в обратных кавычках: `` `Fe2(SO4)3` ``, `` `Fe^3+` ``, `` `SO4^2-` ``. Цифра после буквы или скобки — индекс, `^…` — заряд. `**жирный**`.

**Задания** (`skill` — id навыка, `points` — 1 или 2, `explain` — пояснение после ответа):

```json
{ "type": "single", "text": "…", "options": ["…", "…"], "answer": 0 }
{ "type": "multi",  "text": "Выберите два…", "options": ["…"], "answer": [1, 3] }
{ "type": "match",  "text": "…", "left": ["А…", "Б…", "В…"], "right": ["1…", "2…"], "answer": [1, 0, 1], "points": 2 }
{ "type": "number", "text": "…", "answer": 9.8, "unit": "г", "tol": 0.05 }
{ "type": "order",  "text": "Расположите…", "options": ["…"], "answer": [2, 0, 1] }
```

Индексы в `answer` начинаются с 0.

**Блоки шпаргалки:** `list` (`items`), `table` (`head`, `rows`), `formula` (`items`, `note`), `tubes` (`items`: `f`, `name`, `color`, `gas`, `smell`), `solubility` (таблица растворимости).

**Разборы:** `{ "title", "problem", "steps": [{ "text", "why" }] }`. Для задачи «реши сам» добавьте `"guided": true` и у шагов — `"ask"` и `"choices"` (первый вариант — верный, на экране они перемешиваются).

**Карточки:** `{ "skill", "front", "back" }`.

**Интерактивные уроки** (`lessons`) — последовательность экранов:

```json
{ "id": "solution", "title": "Массовая доля в растворе", "skill": "wsol", "screens": [
  { "type": "text", "title": "Раствор = вещество + вода", "text": "…", "formula": "ω = m(в-ва) / m(р-ра)" },
  { "type": "widget", "widget": "fraction", "params": { "s0": 5, "w0": 50 },
    "goal": { "w": 10 }, "goalText": "Приготовьте раствор 10 %", "after": "10 г соли + 90 г воды" },
  { "type": "question", "qtype": "number", "text": "…", "answer": 10, "unit": "%" }
]}
```

Виджеты (`assets/js/lib/widgets.js`):

| Виджет | Параметры | Цель |
|---|---|---|
| `mole` | `f`, `M`, `max`, `step`, `m0` | `{ "n": 2 }` — набрать количество вещества |
| `fraction` | `solute`, `s0`, `w0`, `maxSolute`, `maxWater`, `stepWater` | `{ "w": 10, "total": 250 }` |
| `molar` | `formula`, `atoms: [["Ca",40,1], …]` | `{ "pick": "Ca" }` — собрать формулу и выбрать элемент |
| `ratio` | `equation`, `given`, `find`, `kGiven`, `kFind`, `max`, `step` | `{ "find": 0.3 }` или `{ "given": 0.6 }` |
| `cancel` | `a`, `b` — id веществ из лаборатории | вычеркнуть все ионы-зрители |
| `mix` | `options: ["CuSO4", "NaOH", …]` | `{ "color": "голубой" }`, `{ "gas": true }`, `{ "smell": true }` |

Новый виджет — функция в `WIDGETS` в том же файле.

Новый тип страницы: файл `assets/js/views/<имя>.js` с функцией `render(root, arg, ctx)` и имя в списке `VIEWS` в `assets/js/app.js`. Адрес — `#<имя>` или `#<имя>-<аргумент>`.

## Отчёты преподавателю

Ответы ученика могут автоматически приходить в вашу Google-таблицу: что ответил, верно ли, был ли уверен, сколько времени думал. Ответы, данные без интернета, копятся и отправляются позже.

1. Откройте `tools/google-apps-script.gs` и выполните шаги из комментария в начале файла.
2. Вставьте полученный адрес в `content/manifest.json`:

```json
{ "reportUrl": "https://script.google.com/macros/s/…/exec" }
```

**Несколько учеников.** Все ответы идут в одну таблицу:

- «Ответы» — все ответы всех учеников, у каждой строки есть имя и код устройства;
- «👤 Имя» — отдельный лист на каждого ученика (создаётся сам при первом ответе);
- «Сводка» — итог по ученикам, точность по навыкам, уверенные ошибки, активность по дням;
- «Ученики» — впишите адрес сайта и имена: формула выдаст персональные ссылки вида `…/?s=Иван%20Петров`.

По персональной ссылке имя запоминается автоматически, без ручного ввода и опечаток. Без ссылки ученик один раз вводит имя на главной. Если `reportUrl` пуст, ничего не отправляется — остаётся кнопка «Скопировать отчёт» на странице «Прогресс».

## Совместная доска

Кнопка «Создать новую комнату» открывает Excalidraw с новой комнатой — отправьте ссылку ученику. Чтобы на всех занятиях была одна и та же доска, вставьте ссылку в `content/manifest.json` → `"liveBoard"`.

## PWA и обновления

Контент (`content/`) загружается из сети при каждом открытии — исправления видны сразу. Код и стили берутся из кэша и обновляются в фоне. После крупных изменений кода поменяйте `CACHE` в `sw.js` (например, `chem-oge-v2`), чтобы у ученика всё обновилось за одно открытие.

## Данные

Прогресс хранится в `localStorage` браузера. На странице «Прогресс» можно скопировать данные и загрузить их на другом устройстве.
